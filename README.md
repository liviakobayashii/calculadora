# 🧮 Calculadora JS

Uma calculadora simples feita com HTML, CSS e JavaScript. O sistema permite realizar operações matemáticas básicas utilizando tanto cliques nos botões quanto o teclado. Ideal para treinar manipulação do DOM e lógica com funções em JavaScript.

Deploy do projeto: https://liviakobayashii.github.io/calculadora

## Funcionalidades

* Realizar operações básicas de adição, subtração, multiplicação e divisão.
* Suporte a parênteses para cálculos mais complexos.
* Botão para limpar o display e apagar o último dígito.
* Executa o cálculo ao pressionar a tecla "Enter".
* Interface responsiva.

## Tecnologias utilizadas

* HTML5  
* CSS3  
* JavaScript
